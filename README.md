# Focus - Task Management App

Data Analyst | *Construindo a transição para Engenharia de Dados*

Um aplicativo desktop minimalista focado em "fricção zero", projetado para otimizar rotinas de estudo e produtividade. Inspirado na estética clean da Apple, o Focus foi construído para integração total com o ecossistema Windows.

**Desenvolvimento 100% impulsionado por IA**
Este projeto foi arquitetado e codificado integralmente através de Engenharia de Prompts com Inteligência Artificial. O objetivo principal foi demonstrar a capacidade de transformar requisitos de negócio, persistência de dados e design de interface em um produto escalável e funcional com máxima velocidade e objetividade.

**Stack Tecnológico**
* **Python 3:** Lógica central e gerenciamento de processos.
* **SQLite:** Modelagem e persistência de dados local (banco offline).
* **CustomTkinter:** Renderização da interface frameless em Dark Mode.
* **Windows API (ctypes):** Integração profunda com o SO (Taskbar, Alt+Tab, DPI Awareness).

**Principais Funcionalidades**
* **Foco Automático (Global Typing):** Qualquer tecla pressionada foca automaticamente no input, reduzindo cliques.
* **Persistência Segura:** Dados gravados localmente em SQLite, garantindo que as tarefas permaneçam a salvo após o desligamento do sistema.
* **Inbox Mode & Calendário:** Separação entre tarefas de longo prazo e tarefas diárias com navegação visual.
* **Comportamento Nativo:** Splash screen imersiva, responsividade na maximização (respeitando a barra de tarefas) e atalhos automatizados de inicialização.

**Status do Projeto**
Concluído e totalmente testado.
